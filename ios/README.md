# iOS

This directory will hold the minimal probe application, eventual `RigTetherKit` Swift
package, and reference application.

M0 must first establish which control transport is available to a normally distributed
iOS application. No private API or unverified entitlement assumption may become a
project dependency.

This directory owns the Apple platform adapter, not the canonical device contract.
AVFAudio, Core Bluetooth, app-lifecycle, and permission behavior must not leak into
shared protocol definitions, firmware guarantees, or safety semantics.
