# Security and safety reports

Use GitHub's private vulnerability-reporting or security-advisory path for issues that
could cause unintended transmission, persistent PTT, damaging voltage or current,
unsafe firmware update behavior, credential exposure, or control by an unintended
host.

Do not publish an exploit, unsafe wiring recipe, or reproducible unintended-transmit
sequence before the maintainer has had a reasonable opportunity to triage it.

RigTether is pre-prototype software and hardware. No repository artifact should be
assumed safe for unattended transmission or production use unless a release says so
explicitly.
