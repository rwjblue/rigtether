# Initial GitHub bootstrap plan

This directory is the reproducible seed for the repository's initial labels,
milestones, tracking issues, and focused work. Run `mise run bootstrap-github` after
the repository exists, or `mise run publish` to create and seed it.

The bootstrap is idempotent by exact issue title and updates generated relationship
links after all issue numbers are known.

After publication, GitHub Issues become the durable tracker. Do not maintain a second,
divergent backlog in these files. Change the manifests only when intentionally fixing
the reproducible bootstrap itself.
